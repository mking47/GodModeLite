## 4. v5 功能实现核对（静态）

- **唯一悬浮球**：无障碍服务只创建 1 个 FloatingBall（`cleanupAll` 幂等）；RulesProvider 新增 `a11y_connected` 列，ModuleEngine 读取后当无障碍球存在时移除/不创建模块球。
- **只能手动显示**：BlockerService `onServiceConnected` 不再自动显示，强制 `ballVisible=false` 并写配置 false；MainActivity `onResume` 不再恢复悬浮球；开关读取服务运行期 `isBallVisible()`；无服务时打开开关会被拒绝并回弹。
- **主动退出后台**：`BlockerService.shutdownSelf()` 隐藏球/清蒙版/写配置 + API24+ 反射 `disableSelf()`；MainActivity「更多 → 退出并关闭后台」确认后 `finishAndRemoveTask()` + `Process.killProcess`；无开机广播/前台服务，不会自动启动。
- **图标**：Pillow 重绘「眼睛 + 红色斜杠」1024px 主图 → 5 组 mipmap + 自适应图标前景 vector。
- **列表/瀑布流**：ConfigStore 新增 `LAYOUT_LIST/WATERFALL` + `get/setLayoutMode`；AppListAdapter 支持双列卡片（Unit 分组、卡片复用、点击回调），标题行独占整行。
- **内存**：`ConfigStore.stats()` / `packageStats()` 不再拷贝规则；应用列表 15s 缓存；`onTrimMemory` 清图标缓存；自动备份信息子线程读取；图层选择单画布；节点回收。

1. adb 未连设备，未做安装/截图验证。

## 7. 用户侧验证清单

1. 安装 → 打开：「悬浮球」开关默认关，界面无球；打开开关出现**一个**球；关闭 App 再打开 App，开关仍关、无球（不会自动恢复）。
2. 开 LSPosed 模块 + 作用域 → 目标应用里不应出现第二个球（已有无障碍球时）。
3. 拖球换位置 → 关球 → 重开球，位置应记住。
4. 「更多 → 布局」切「瀑布流」→ 应用列表变双列卡片；切回「列表」恢复单列。
5. 「更多 → 退出并关闭后台」→ 球消失、App 退出；等 10 秒确认后台没有自动启动。
6. 桌面图标为「眼睛 + 红色斜杠」新图标。

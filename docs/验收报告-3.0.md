## 4. 功能实现核对（静态）

- **悬浮球自定义**：ConfigStore 5 样式 + 3 尺寸 + 3 透明度；FloatingBall `applyStyle()` 保球心、updateViewLayout；模块 RuleClient 读 `ball_style/size/alpha` 列并按同样样式绘制。
- **关闭即隐藏**：MainActivity `onResume` 恢复显示、`onDestroy`（非配置变化）调 `BlockerService.hideBallForAppExit()`（会话级隐藏不写配置）；长按菜单「关闭悬浮球」持久关闭。
- **信息详细**：状态卡 5 行；规则行三行（mode/viewId/类名/时间/坐标）；列表徽章。
- **排序/筛选/置顶**：智能排序分组标题行（不可点）+ 名称/规则数排序；筛选全部/有规则；与搜索叠加。
- **使用说明书**：HelpActivity 深色 7 节 + 命令块；manifest 已注册。
- **选中界面清晰度**：顶部副标题、胶囊取消、动作卡 52dp/16sp 三按钮（绿/红/深灰）、两行信息、3dp 绿框 + 外发光。
- **内存**：图层选择单 View onDraw；节点遍历 recycle + MAX_VISITED 3000；图标 LruCache(48) 异步；模块自绘上限 200、关闭清引用。

## 6. 未能验证（需真机）

1. 悬浮球触感/拖动、`TYPE_ACCESSIBILITY_OVERLAY` 在具体 ROM 的触摸与层级（有 TYPE_APPLICATION_OVERLAY/TYPE_SYSTEM_ALERT 降级重试）。
2. root 一键配置三条命令与 `setprop debug.layout` 在用户 Magisk/KernelSU 环境的行为。
3. LSPosed 模块真删效果与模块悬浮球样式同步（需真机装 LSPosed 验证）。
4. 关闭 App（划掉最近任务）后悬浮球消失的行为（代码按 `onDestroy` 非配置变化触发，个别 ROM 若未触发可用球长按菜单「关闭悬浮球」兜底）。
5. Android 13/14 侧载「允许受限设置」。

## 7. 用户侧验证清单

1. 安装 → 打开 → 一键配置（root）→ 无障碍变绿。
2. 悬浮球：单击进图层选择；长按菜单；主界面「悬浮球样式」换 5 种样式/尺寸/透明度，看实时变化。
3. 图层选择：点元素 → 看清两行信息与三个大按钮 → 「遮挡」生效。
4. 关闭 App（返回/划掉）→ 其它界面不再有悬浮球；重开 App 恢复。
5. 应用列表：排序（智能置顶/名称/规则数）、筛选（全部/有规则）、搜索叠加；有规则的 App 在智能排序下置顶。
6. 主界面「使用说明书」打开 7 节说明页。
7. LSPosed：启用模块 + 勾作用域 → 目标应用加「真删」规则 → 元素真正消失。

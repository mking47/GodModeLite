## 4. v4 功能实现核对（静态）

- **悬浮球默认关闭**：ConfigStore `ballVisible` 默认 false（3 处）；服务连接只在配置为 true 时显示；主界面开关是唯一打开入口。
- **关闭 App 保持关闭**：MainActivity `onDestroy`（非配置变化）隐藏球并 `setBallVisible(false)`；`onResume` 仅在开关为开时恢复。
- **位置记忆**：FloatingBall `resolvePosition()` 读 `ConfigStore.getBallX/Y`，拖动结束写回。
- **自动备份**：`AutoBackupManager`（新类）——应用默认目录 `files/backup/`、文件名 `rules-yyyyMMdd-HHmmss.json`、`MAX_BACKUPS=2`、`pruneDir` 按时间删旧；开启屏蔽触发 + 启动补备份；主界面自动备份管理弹窗。
- **模块同步**：RulesProvider 新增 `ball_visible` 列；RuleClient 读取；ModuleEngine 在 false 时移除模块悬浮球。
- **图标**：Pillow 生成盾牌+眼睛+禁止斜杠 1024px 主图 → 5 组 mipmap PNG + 自适应图标（前景 vector + 深色底）。
- **内存**：图层选择单 View onDraw（上限 300/模块 200）、节点遍历回收 + MAX_VISITED=3000、图标 LruCache(48) 异步 + `trimMemory`、应用列表 15s 缓存、自动备份信息子线程读取。
- **界面**：标题栏图标+版本、按钮 4 行→3 行、「更多…」菜单、自动备份入口行。

## 5. 自动化测试

## 7. 用户侧验证清单

1. 安装 → 打开：悬浮球应**不出现**（默认关）；打开「悬浮球」开关才出现。
2. 拖动球到别处 → 关闭 App（划掉）→ 其它界面无球；重开 App，开关为关；手动打开后球应回到上次位置。
3. 打开「启用屏蔽」→ 提示「已自动备份规则」；点「自动备份：N 份 ›」查看目录与两份文件；再开一次屏蔽应仍只有 2 份（旧的被删）。
4. 桌面图标应是新的深色盾牌眼睛斜杠图标（Android 8+ 为自适应圆形/方形裁切）。
5. 其它 v3 功能回归：图层选择、遮挡/真删、排序筛选、说明书、备份恢复。
6. LSPosed：启用模块 + 作用域 → 「真删」规则生效；主应用关掉悬浮球后目标应用里的模块球应消失。

# 上帝模式 Lite v4.0 · 使用说明

> root 免框架 + LSPosed 模块双模式界面工具。v4 重点：**悬浮球只能手动开关才显示**、关闭 App 后不在任何界面出现、记住悬浮球位置、**开启屏蔽自动备份（保留 2 份）**、全新应用图标、内存与界面优化。
> APK：`GodModeLite-4.0.apk`（包名 `com.dsh.godmodelite`，versionCode 4 / 4.0，minSdk 21 / targetSdk 28，约 225 KB，内置测试签名）

---

## 一、v4 更新点

1. **悬浮球默认关闭，只能手动打开**：新安装/升级后悬浮球不再自动出现；只有在主界面手动打开「悬浮球」开关才会显示。关闭后不会在任何界面出现（即使无障碍、悬浮窗权限都有）。
2. **记住悬浮球位置**：拖动后保存位置，下次手动打开时仍在原位置。
3. **关闭 App 即保持关闭**：按返回键 / 最近任务划掉本应用后，悬浮球隐藏并保持关闭，需要再次打开 App 手动开启；按 Home 键只是切后台，不影响。
4. **开启屏蔽自动备份**：打开「启用屏蔽」时自动把规则备份到软件默认目录，只保留最近 **2 份**，新备份按时间覆盖旧备份；App 启动当天没备份过会补一份。
5. **全新应用图标**：深色盾牌 + 眼睛 + 红色禁止斜杠，含 Android 8+ 自适应图标与多密度 PNG。
6. **内存优化**：图层选择单画布自绘、节点遍历即用即回收、应用图标 LruCache + 后台加载、应用列表 15 秒缓存、内存紧张自动清图标缓存、自动备份信息子线程读取。
7. **界面优化**：更紧凑的首页（标题栏带图标/版本号）、按钮从 4 行减到 3 行、新增「更多…」菜单（无障碍设置/刷新/LSPosed/自动备份）、右上「自动备份：N 份 ›」入口。

## 二、两种模式（沿用）

| | root 免框架模式 | LSPosed 模块模式（真删） |
|---|---|---|
| 前提 | 有 root 或手动开无障碍 | root + LSPosed |
| 效果 | 悬浮窗遮挡 + 拦截点击 | 目标进程内 `setVisibility(GONE)` 真正删除 |
| 悬浮球 | 全局球（手动开关） | 目标应用内球（跟随主应用开关） |

> root 不能跨进程删 View（Android 进程隔离），真删必须 LSPosed 模块；两种模式规则互通。

## 三、安装与 root 一键配置

1. 安装 APK → 打开 App。
2. 点「一键配置（root）」自动执行：
   ```sh
   settings put secure enabled_accessibility_services "<原列表>:com.dsh.godmodelite/com.dsh.godmodelite.a11y.BlockerService"
   settings put secure accessibility_enabled 1
   appops set com.dsh.godmodelite SYSTEM_ALERT_WINDOW allow
   ```
3. 无 root：手动打开无障碍 + 「显示在其他应用上层」权限。
4. 「布局边界」开关（root）：`setprop debug.layout` 全局显示所有控件边框，重启手机自动关闭。

## 四、悬浮球（手动开关）

- 主界面「悬浮球」开关打开后，屏幕出现悬浮球（默认 48dp 眼睛样式）。
- 拖动移动 → 松手记住位置；单击进入图层选择；长按菜单：打开 App / 关闭悬浮球（持久关闭）/ 隐藏悬浮球 / 取消。
- 「悬浮球样式」：眼睛 / 圆点 / 盾牌 / 文字「隐」/ 禁止斜杠，3 档尺寸、3 档透明度，实时生效。
- **关闭 App 后悬浮球不会留在任何界面**；下次打开 App 需要手动再开。
- root 模式与 LSPosed 模块模式的球都遵循这个开关（模块通过内容提供者读取同一配置）。

## 五、图层选择

点悬浮球 / 主界面「图层选择」/ 规则页「图层选择」→ 屏幕上所有可见控件画彩色边框（6 色按层级、带文字/ID 标签、最多 300 个），顶部显示「共 N 个图层 · 当前包名」。
点元素 → 高亮 + 底部动作卡（52dp 大按钮）：
- **遮挡**（绿）：白色蒙版盖住 + 拦截点击。
- **真删**（红）：LSPosed 模块启用后真正 GONE，未启用按遮挡处理。
- **取消**（灰）。

## 六、自动备份（v4）

- **触发**：每次打开「启用屏蔽」自动备份一次；App 启动当天还没备份过会补一份。
- **目录**：`Android/data/com.dsh.godmodelite/files/backup/`（应用默认目录，不需要存储权限）。
- **保留**：最近 2 份，`rules-yyyyMMdd-HHmmss.json`，按时间删除最旧的（循环覆盖）。
- **管理**：点主界面右上「自动备份：N 份 ›」→ 可「立即备份一份 / 恢复最近一份 / 开关自动备份」，弹窗里显示目录和文件时间/大小。
- 手动【备份规则 / 恢复规则】仍走系统文件选择器，支持本作 JSON 与原版「上帝模式」的 `.gzip` 备份。

## 七、LSPosed 模块模式（真删）

1. root 下安装 LSPosed → 重启 → 打开管理器。
2. 「模块」→ 勾选「上帝模式 Lite」→ 作用域勾选目标应用（不要勾系统应用）。
3. 强制停止目标应用 → 重新打开。
4. App 里给该应用加「真删」规则，元素会真正消失。
5. 日志：LSPosed 管理器 → 日志 → 搜 `GodModeLite`。

## 八、界面说明

- 状态卡：root / 无障碍 / 规则统计（共 N · 遮挡 A · 真删 B）/ 悬浮球（显示中·样式）/ LSPosed。
- 按钮：一键配置、图层选择、使用说明书；悬浮球样式、备份规则、恢复规则；排序、筛选、更多…。
- 开关：启用屏蔽 / 悬浮球；布局边界 + 自动备份入口。
- 应用列表：图标 + 名称 + 包名 + 「遮挡 N」「真删 M」徽章；智能排序时有规则的应用置顶分组。

## 九、兼容性 / 限制

- Android 5.0 ~ 14；Android 13/14 侧载需先「允许受限设置」。
- WebView/Flutter/Unity 自绘元素读不到；小于 4px、不可见节点也会跳过。
- 模块模式需要 LSPosed；系统应用不要加作用域。
- 规则 Provider 为跨进程同步而 exported（无权限），App 无 INTERNET 权限。

# 上帝模式 Lite v4.0

在 v3.0 基础上优化悬浮球、自动备份、应用图标、内存与操作界面。

## 新功能 / 改进（v4.0）

- **悬浮球只能手动打开**：新安装/升级后默认关闭，只在主界面打开「悬浮球」开关才显示；关闭后不会出现在任何界面（即使无障碍、悬浮窗权限都在），LSPosed 模块内的球也同步遵守。
- **记住悬浮球位置**：拖动后保存坐标，下次手动打开仍在原位置；按 Home 键切后台不隐藏。
- **关闭 App 保持关闭**：返回键 / 最近任务划掉后悬浮球隐藏并保持关闭，需要再次打开 App 手动开启。
- **开启屏蔽自动备份**：打开「启用屏蔽」自动备份规则到应用默认目录 `Android/data/com.dsh.godmodelite/files/backup/`，保留最近 **2 份**，新备份按时间覆盖旧备份；App 当天首次启动也会补一份；主界面右上「自动备份：N 份 ›」可立即备份 / 恢复最近一份 / 开关自动备份。
- **全新应用图标**：深色盾牌 + 眼睛 + 红色禁止斜杠，含 Android 8+ 自适应图标与 5 组密度 PNG。
- **内存优化**：图层选择单画布自绘（上限 300/模块 200）、无障碍节点即用即回收（上限 3000）、应用图标 LruCache(48) 后台加载、应用列表 15 秒缓存、`onTrimMemory` 清理图标缓存、备份信息子线程读取。
- **界面优化**：标题栏增加图标与版本号，按钮由 4 行压缩到 3 行，新增「更多…」菜单（无障碍设置/刷新/LSPosed/自动备份），自动备份入口常驻。

## 已知限制

- root 模式为「视觉遮挡 + 点击拦截」，不是从布局删除；真删需 LSPosed 模块模式。
- WebView/Flutter/Unity 自绘界面、`isVisibleToUser=false` 节点可能识别不到。
- Android 13/14 侧载 App 需先「允许受限设置」才能开无障碍。

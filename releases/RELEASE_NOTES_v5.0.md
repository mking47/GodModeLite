# 上帝模式 Lite v5.0

在 v4.0 基础上优化悬浮球唯一性/手动开关、主动退出后台、应用图标、应用列表布局与内存。

## 新功能 / 改进（v5.0）

- **全局唯一悬浮球**：无障碍悬浮球存在时，LSPosed 模块不再加第二个球；任何界面最多一个悬浮图标。
- **只能手动显示**：默认关闭，只有主界面手动打开「悬浮球」开关才显示；**重新打开 App 也不会自动恢复**；关闭后任何界面都不出现。
- **主动退出并关闭后台**：「更多… → 退出并关闭后台（停止服务）」：关闭悬浮球 → 解绑无障碍服务（API24+ `disableSelf`）→ 结束进程，之后系统不会自动启动；Android 7 以下引导先手动关闭无障碍。
- **新应用图标**：眼睛 + 红色禁止斜杠（深色圆角底），含自适应图标与 5 组密度 PNG。
- **列表 / 瀑布流布局**：「更多… → 布局」切换单列列表或双列圆角卡片瀑布流，已配置应用仍智能置顶。
- **内存优化**：规则统计不再拷贝列表（`ConfigStore.stats()/packageStats()`）、应用列表 15 秒缓存、图标 LruCache + 后台线程 + `onTrimMemory` 清理、图层选择单画布、无障碍节点即用即回收。

## 已知限制

- root 模式为「视觉遮挡 + 点击拦截」，不是从布局删除；真删需 LSPosed 模块模式。
- WebView/Flutter/Unity 自绘界面、`isVisibleToUser=false` 节点可能识别不到。
- Android 13/14 侧载 App 需先「允许受限设置」才能开无障碍。
- 「退出并关闭后台」依赖系统 `disableSelf`，个别深度定制系统可能仍会重启无障碍服务。

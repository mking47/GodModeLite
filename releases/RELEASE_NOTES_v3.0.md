# 上帝模式 Lite v3.0

首个公开发布版本。双模式界面元素工具：root 免框架遮挡 + LSPosed 模块真删。

## 新功能（v3.0）

- 悬浮球：5 种图标样式（眼睛/圆点/盾牌/「隐」/禁止斜杠）× 3 尺寸 × 3 档透明度，实时生效
- 关闭 App 后悬浮球从其它界面消失（返回/划掉最近任务），重开恢复
- 主界面信息更详细：root / 无障碍连接 / 规则统计（共 N·遮挡 A·真删 B）/ 悬浮球状态 / LSPosed
- 应用列表：图标 + 「遮挡 N」「真删 M」徽章；智能排序（已配置置顶分组）/ 名称 / 规则数；全部 / 仅有规则筛选；搜索叠加
- 独立「使用说明书」页面（7 节，含 root 命令块与 LSPosed 步骤）
- 图层选择界面清晰度提升：顶部图层数/包名、胶囊取消、52dp 大按钮（遮挡绿/真删红/取消灰）、两行元素信息、绿框+外发光高亮
- 内存优化：图层选择单画布自绘（上限 300/模块 200）、无障碍节点用完即回收、应用图标 LruCache(48) 异步加载
- 保留：root 一键配置、系统布局边界开关（`debug.layout`）、备份/恢复（兼容原版 `.gzip` 备份）、LSPosed 真删

## 已知限制

- root 模式为「视觉遮挡 + 点击拦截」，不是从布局删除；真删需 LSPosed 模块模式。
- WebView/Flutter/Unity 自绘界面、`isVisibleToUser=false` 节点可能识别不到。
- Android 13/14 侧载 App 需先「允许受限设置」才能开无障碍。
- 模块作用域不要勾系统应用。
